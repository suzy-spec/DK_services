🔍 리포트 개요

경쟁사 KuP Express의 호텔 당일배송 서비스를 직접 테스트하여, DK Korea local delivery 서비스 기획에 참고할 수 있는 실사용 데이터와 인사이트를 도출하기 위해 작성된 내부 분석 보고서입니다.

왜 이 서비스를 직접 테스트했는가

조사 방법실사용자 2인(결제 담당 / 배송 픽업 담당)을 통한 서비스 직접 테스트 + Q&A 인터뷰 방식으로 정성적 데이터 수집
테스트 일시2026년 5월 14일 (주문 결제) — 2026년 5월 15일 (물품 수령)

Part 3 — 시사점

1
DK가 참고할 점 — KuP의 강점
벤치마킹 적용 가능한 긍정 요소
참고 01 · 알림 체계
단계별 푸시 알림 + 이메일 이중 발송 구조
KuP는 주문 확인부터 배송 완료까지 4단계 푸시 알림을 제공하며, 완료 시에는 배송 사진이 포함된 화면을 노출. DK도 Korea local delivery 서비스에서 단계별 상태 알림(이메일 + 앱 푸시)을 동급 이상으로 구성해야 고객 신뢰도 확보 가능.
참고 02 · 주문 완료 이메일
주문 즉시 인보이스 이메일 자동 발송
결제 성공 직후 정형화된 인보이스 메일이 발송되어 고객이 영수증을 보유. 배송 완료 시에도 상세 내역 메일 재발송. DK 적용 시 고객 불안감 해소 및 CS 문의 감소 효과 기대.
참고 03 · 가격 포지셔닝
한국 현지 판매가 수준 유지 + 배송비 0원
테스트 사용자가 서비스 추천 의향을 밝힌 핵심 이유. "비싸지 않음"이 명확한 가치 제안. DK도 Korea local delivery에서 배송비 정책 및 마진 구조를 투명하게 노출하여 '가격 합리성' 메시지를 강화할 수 있음.
참고 04 · 최소 주문 금액 없음
소액 주문 허용으로 진입 장벽 제거
단돈 5,000원짜리 스낵도 주문 가능. 외국인 여행객이 '시험 삼아' 써볼 수 있는 구조. DK도 최소 주문 금액 기준을 최대한 낮게 설정하거나 없애는 방향을 검토할 것.
2
DK의 차별화 포인트 — KuP의 약점
DK가 우위를 점할 수 있는 영역
차별화 01 · 고객지원
인앱 즉시 지원 채널 부재 — DK가 우위 확보 가능
KuP는 고객지원이 이메일 전용으로, 앱 이탈 + 즉시 응답 불가 구조. 테스트 사용자가 꼽은 최대 불편 사항. DK가 채팅 CS 또는 인앱 지원 채널을 제공한다면 명확한 경쟁 우위 확보 가능.
차별화 02 · 수령 안전성
오픈 캐비닛 수령 → DK의 안전 수령 구조가 강점
KuP는 호텔 협조 여부가 일관적이지 않고, 실제 수령 장소가 비밀번호 없는 공용 보관소. 도난 위험에 노출. DK는 호텔 프론트 직접 인계 + 신원 확인 프로세스 + 미수령 시 국제배송 전환 안전망을 강점으로 홍보할 것.
차별화 03 · 결제 안정성
결제 실패 UX — DK는 안정적 결제 흐름 확보 필요
해외 카드 결제 시 무반응으로 3회 시도. 결제 실패/성공 피드백이 명확하지 않아 사용자 혼란. DK는 PAYVERSE 등 결제 PG 연동 시 로딩 인디케이터, 성공/실패 명확한 피드백 UI를 필수 적용해야 함.
차별화 04 · 상품 범위
KuP 상품군 한정 → DK는 We Buy 구매대행으로 무한 확장
KuP는 자체 큐레이션 상품만 제공하여 선택 폭이 제한적. DK는 DK Store + We Buy 구매대행으로 사실상 한국 전체 이커머스 상품을 커버 가능. 이 점을 명확히 마케팅 메시지로 활용할 것.
